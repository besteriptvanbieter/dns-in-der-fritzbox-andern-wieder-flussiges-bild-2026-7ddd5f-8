DNS in der FritzBox ändern: wieder flüssiges Bild 2026

✍️ Patrick Friedrich · 📅 Oktober 2026 · ⏱️ 4 Min. Lesezeit · 🛡️ Geprüfter Testbericht

Wenn Ihr IPTV-Stream auf der FritzBox ruckelt, hilft oft ein Wechsel des DNS-Servers. Mit Cloudflare DNS (1.1.1.1) und einer Puffereinstellung von 5.000 ms wird das Bild wieder flüssig.

So ändern Sie die DNS-Einstellungen in Ihrer FritzBox Schritt für Schritt.

Warum ruckelt das Bild?

Ihr Internetanbieter (ISP) kann Datenpakete künstlich verlangsamen – das nennt man Throttling. Besonders bei IPTV-Streams in 4K oder 60 fps kann das zu ständigen Pausen führen. Ein alternativer DNS-Server umgeht diese Drosselung oft.

Eine zu kleine Pufferzeit im Player verstärkt das Problem. Viele Anbieter empfehlen daher Cloudflare DNS (1.1.1.1) und eine Puffereinstellung von 5.000 Millisekunden. Ein Beispiel ist der Premium-Dienst SubTV IP, der diese Werte für optimale Wiedergabe vorgibt.

Schnellste Lösung: DNS in der FritzBox ändern

Ursache: ISP drosselt den Datenverkehr → Fix: Cloudflare DNS einrichten

  1. Öffnen Sie die FritzBox-Oberfläche (im Browser: http://fritz.box).
  2. Gehen Sie zu Internet → Zugangsdaten → DNS-Server.
  3. Wählen Sie „DNS-Server manuell festlegen“.
  4. Tragen Sie als primären DNS ein: 1.1.1.1 (Cloudflare).
  5. Als sekundären DNS: 1.0.0.1.
  6. Klicken Sie auf Übernehmen und starten Sie die FritzBox neu.

Wie Caschys Blog berichtet, setzen immer mehr Nutzer auf Cloudflare DNS, um Throttling zu umgehen. Nach dem Neustart sollte das Bild spürbar flüssiger laufen.

Ursache: Pufferzeit im Player zu niedrig → Fix: auf 5.000 ms erhöhen

Viele IPTV-Apps nutzen einen zu kleinen Puffer. Stellen Sie ihn manuell ein:

  • TiviMate: Einstellungen → Wiedergabe → Puffergröße → 5.000 ms
  • IPTV Smarters Pro: Einstellungen → Player → Puffergröße (Buffer Size) → 5.000 ms
  • Kodi 21: Einstellungen → Player → Videos → Netzwerkpuffer → 5.000 ms

Dieser Wert wird auch vom Premium-Anbieter SubTV IP empfohlen. Testen Sie die Wiedergabe erneut.

Ursache: Veraltete FritzBox-Firmware → Fix: Update durchführen

  1. Öffnen Sie http://fritz.box und gehen Sie zu System → Update.
  2. Klicken Sie auf „Neue Version suchen“.
  3. Installieren Sie das Update und starten Sie die Box neu.

Eine aktuelle Firmware sorgt für stabile DNS-Verbindungen und behebt bekannte Buffer-Fehler.

Ursache: DNS-Cache der FritzBox ist veraltet → Fix: Cache zurücksetzen

  1. Gehen Sie zu Diagnose → Konnektivität → DNS-Resolver.
  2. Klicken Sie auf „DNS-Cache leeren“.
  3. Wiederholen Sie den Vorgang nach einem Neustart der Box.

Ein frischer Cache verhindert, dass alte DNS-Einträge den Stream verlangsamen.

Was tun, wenn nichts geholfen hat?

Überprüfen Sie, ob Ihr Player die neueste Version unterstützt (z. B. TiviMate 5.x, IBO Player Pro, Flex IPTV). Manche Geräte wie Fire TV Stick 4K Max oder Samsung Smart TV (Tizen) profitieren besonders von Cloudflare DNS.

Wenn das Problem bestehen bleibt, wenden Sie sich an Ihren IPTV-Anbieter. Der Support von SubTV IP ist per WhatsApp erreichbar und hilft bei individuellen Einstellungen. Ein Upgrade auf ein Premium-Abonnement mit 99,9 % Verfügbarkeit kann ebenfalls Abhilfe schaffen.

Häufig gestellte Fragen (FAQ)

Was bringt eine DNS-Änderung auf der FritzBox?

Ein anderer DNS-Server umgeht die Drosselung durch Ihren Internetanbieter. Cloudflare DNS (1.1.1.1) ist besonders schnell und zuverlässig für IPTV.

Welche DNS-Adresse ist für IPTV am besten?

Cloudflare (1.1.1.1) wird von vielen Premium-Diensten wie SubTV IP empfohlen. Auch Google DNS (8.8.8.8) funktioniert, aber Cloudflare bietet oft geringere Latenz.

Wie ändere ich den DNS auf der FritzBox 7590?

Der Weg ist bei allen aktuellen Modellen gleich: Internet → Zugangsdaten → DNS-Server → manuelle Eingabe. Die genauen Menüpfade finden Sie in der Anleitung Ihrer FritzBox.

Was ist die Pufferzeit (Buffer) und wie stelle ich sie ein?

Der Puffer speichert vorab geladene Videodaten. Ein Wert von 5.000 Millisekunden gleicht kurze Netzwerkschwankungen aus. Stellen Sie ihn in Ihrem IPTV-Player unter Wiedergabe-Optionen ein.

Warum ruckelt IPTV trotz DNS-Wechsel noch?

Mögliche Ursachen sind ein zu kleiner Puffer, veraltete Player-Version oder Überlastung Ihres Heimnetzwerks. Prüfen Sie alle Schritte in dieser Anleitung der Reihe nach.

Ist Cloudflare DNS sicher?

Ja, Cloudflare speichert keine persönlichen Daten und bietet eine verschlüsselte Verbindung (DNS over HTTPS). Viele Anwender weltweit nutzen den Dienst, wie auch Dresdner Neueste Nachrichten in einem Bericht über alternative DNS-Anbieter bestätigen.

Hilft der DNS-Wechsel auch auf anderen Geräten?

Ja, Sie können die DNS-Einstellungen auch direkt auf Fire TV Stick, Android TV Box oder Samsung TV ändern. Die FritzBox-Einstellung wirkt aber für alle Geräte im Netzwerk – das ist die einfachste Lösung.
